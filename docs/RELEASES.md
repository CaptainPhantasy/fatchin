# Releases

## 0.3.0 — November 9, 2026

FatChin now gives setup and recovery the same attention as starting work.

- Failed and stopped work stays visible with specific next steps. Archive and
  restore keep original attempts, results and publication evidence.
- Watches offer validated saved results folders, or guide account/folder selection.
  New repository watches stay inactive until setup and the automation decision.
- Repository and Settings saves preserve nested fleet policy, roles and daily caps.
- Drafts, uncertain publication, missing exports, saved lessons and folder errors
  have recovery paths that preserve the work already done.
- Exploration retains the loaded project and entered versions after failed reads.
- Resume and budget confirmations read current saved scope and usage.
- Provider role routing, per-attempt pacing, halt labels and authoritative merge
  readiness are retained alongside bounded provider budgets and publication guards.
- Enabled secret checks hold publication when a scan cannot be completed.
- The package and web interface report the same release version. Wheels include
  the interface, icons, fonts and linked guides for installations outside a checkout.

The release contains no runtime credentials, saved runs, audit captures, private
service addresses or deployment-specific account data. Credentials and work
records remain in the installer's account, outside the repository and package.
